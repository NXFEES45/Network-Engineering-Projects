###### **Purpose of this Project**

The purpose of the "Inter-VLAN Routing" project is to enable communications between different VLANs whilst isolating departments. This is achieved by implementing a Layer 3 device (i.e. the 1841 router) and configuring sub-interfaces. This is a cost-efficient way of segmenting networks by avoiding the expenses in multiple network devices (this method is known as a "Router-on-a-stick"). Moreover, this allows for scalability as inter-VLAN routing ensures the network remains functional even after adding more end devices and switches. Inter-VLAN Routing also allows for shared access to centralised devices (like servers/printers). Regarding security, segments remain separate except for approved flows of traffic, reducing malware spread.



Asides from the technical points, the projects serve as a means for myself to improve in network engineering by familiarising myself with configuring network devices, protocols etc and also to help other potential network engineers alike in building fluency in the field.
